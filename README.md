# Daily News Brief

Local Windows app that emails **5 trustworthy news headlines** once a day.

Nothing stays running in the background. Saving settings creates a **Windows Task Scheduler** job that runs only at your chosen time.

## Quick start

1. Double-click `start_dashboard.bat`
2. On the dashboard, set:
   - **Emails on/off**
   - **Send time**
   - **Email title**
   - **Recipients**
   - **Comes from** (name, email, password)
3. Click **Save**. The Gmail app password is written to `config.json` on this PC only.

For Gmail, use an [App Password](https://support.google.com/accounts/answer/185833) (not your normal password). `config.json` is not part of the GitHub copy.

Your PC needs to be on at send time.
